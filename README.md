# Полка — читалка для Android

Красивая читалка EPUB и FB2: деревянные полки как в старом iBooks, загиб страницы при листании,
разворот книги на планшете, бионический шрифт, темы и свои шрифты.

## Что умеет

- **Находит книги на телефоне сама** — EPUB, FB2, FB2.ZIP (в том числе из загрузок Telegram и браузера).
  Новые книги появляются на полке при запуске.
- **Кнопка «+»** — добавить файлы вручную. Можно и «Открыть с помощью → Полка» из файлового менеджера или Telegram.
- **Полки** — вид полками или списком; сортировка; поиск; ленточка «новая» и прогресс.
- **Листание** — загиб страницы за пальцем (как в бумажной книге), сдвиг, затухание или без анимации;
  тапы по краям, свайпы, кнопки громкости.
- **Разворот** — на планшете в альбомной ориентации две страницы, лист переворачивается через корешок.
- **Темы страницы** — Белая, Бумага, Сепия, Шалфей, Лаванда, Сумерки, Ночь, Чёрная (белый текст для AMOLED)
  и **Матрица** — зелёные светящиеся буквы на чёрном.
- **Бережный режим для глаз** — готовые стили «Бережный день», «Тёплый вечер», «Мягкая ночь»
  (мягкий контраст, тонированный фон, текст по левому краю, больше воздуха) и **свои стили**:
  настрой оформление и сохрани его под своим названием, переключай по настроению.
  Утолщение букв, межбуквенный и межсловный интервал, затемнение без мерцания, тёплый фильтр,
  напоминание «20-20-20» дать глазам отдых.
- **Шрифты** — Lora, Классика, Inter, Literata, PT Serif, EB Garamond и другие + **свой .ttf/.otf**.
- **Бионическое чтение** — жирное начало слов; настраивается, сколько выделять, насколько жирно,
  и можно приглушить окончания.
- **Цитаты и заметки** — долгое нажатие на текст → маркер одного из 5 цветов, заметка к цитате,
  копировать или поделиться цитатой с автором и названием. Все цитаты книги — в списке «Заметки»,
  можно отправить их все одним сообщением.
- **Закладки** — значок сверху или касание правого верхнего угла страницы, на странице появляется ленточка.
- **Трекер чтения** — цель книг на год, минут в день, серия дней подряд, график недели, прочитанное за год.
- **Подборки на полке** — Все, Читаю, Хочу прочесть, Прочитано и **Цитаты** (все выделения из всех книг,
  касание открывает книгу на месте цитаты). Дочитанная книга сама переезжает в «Прочитано».
- **Полки** — дуб, вишня, орех, тёмная, белое дерево, берёза, серый ясень, венге.
- Оглавление, сноски всплывающим окном, переходы по ссылкам с кнопкой «Вернуться», режим прокрутки,
  запоминание места, яркость, «не гасить экран», полноэкранный режим.

## Как установить

1. На телефоне открой страницу **Releases** этого репозитория и скачай `Polka.apk`.
2. Открой скачанный файл. Android попросит разрешить установку из этого источника — разреши.
3. При первом запуске нажми «Найти книги на телефоне» и включи «Доступ ко всем файлам» для «Полки».

Обновления ставятся поверх — полка и закладки сохраняются.

## Как устроено

- `app/src/main/java/.../MainActivity.java` — оболочка Android: поиск файлов, разрешения, выбор файлов,
  кнопки громкости, полноэкранный режим.
- `app/src/main/assets/web/` — сама читалка (HTML/CSS/JS): разбор EPUB/FB2, полки, движок страниц, анимация.
- `.github/workflows/build.yml` — GitHub собирает APK при каждом изменении и выкладывает его в Releases.
- `dev/` — проверка в обычном браузере: `node dev/server.mjs`, затем тесты `node dev/t_read.mjs`.
